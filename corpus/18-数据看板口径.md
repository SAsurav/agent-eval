# 数据看板指标口径

> 来源：领英海外拓客跟进表.xlsx / 数据看板（公式口径）

## 头部指标

| 指标 | 公式口径 |
| --- | --- |
| 名单总数 | COUNTA(跟进台账 E 列) |
| 已通过 | COUNTIF(状态列,"已建联") + COUNTIF(状态列,其他) |
| 有回复 | COUNTIF(状态列,"已回复") + COUNTIF(状态列,其他) |
| 明确意向 | COUNTIF(状态列,"有意向") + COUNTIF(状态列,其他) |
| 回传表已收 | COUNTIF(回传表列,">0") |
| 注册成功 | COUNTIF(状态列,"已完成") |
| 账号通过率 | 已通过 ÷ 名单总数（空值或 0 时返回空） |

## ① 转化漏斗 —— 看卡在哪一环

| 环节 | 统计口径 | 占名单比 |
| --- | --- | --- |
| 已通过 CONNECTED | COUNTIF(状态列,"已建联") + 其他 | 该环节 ÷ 名单总数 |
| 有回复 REPLIED | COUNTIF(状态列,"已回复") + 其他 | 该环节 ÷ 名单总数 |
| 明确意向 INTERESTED | COUNTIF(状态列,"有意向") + 其他 | 该环节 ÷ 名单总数 |
| 已收回传表 FORM_RECEIVED | COUNTIF(状态列,"已收回传表") + 其他 | 该环节 ÷ 名单总数 |
| 注册成功 REGISTERED | COUNTIF(状态列,"已完成") | 该环节 ÷ 名单总数 |

## ② 来源对比 —— 决定下周名单怎么分配

按来源（赞助商 / 点赞）分别统计：名单数、有回复、明确意向、注册成功、回复率。

回复率 = 有回复 ÷ 该来源名单数。

## ③ 人效对比 —— 谁需要辅导

按负责人统计：名单数、已通过、有回复、注册成功、通过率。

通过率 = 已通过 ÷ 名单数。

## ④ 今日待办与风险预警

| 指标 | 口径 / 处理动作 |
| --- | --- |
| 今日待办 | 下次行动日 ≤ 今天，且状态未结束。每天早上第一件事：按「下次行动日」升序排序处理 |
| 逾期超过 2 天 | 下次行动日已过 2 天仍未动。必须当天清掉，并在日报说明原因 |
| CONNECTED 超 48 小时未发消息 | 黄灯。已通过但 48 小时内没发首条消息 —— 立即补发，这类客户转化率最高 |
| FORM_SENT 超 3 天未提醒 | 黄灯。回传表发出 3 天没动静 —— 提醒一次，只提醒一次 |
| 账号通过率 | 口径：已通过 ÷ 名单总数。安全线 30%，建议稳定在 40% 以上 |
| 账号健康结论 | 低于 30% 输出「减速！当天停止新增邀请，只做跟进」，否则「正常」 |
