# 跟进台账使用说明

> 来源：领英海外拓客跟进表.xlsx / 使用说明

「跟进台账」使用说明
一、字段清单（按列顺序填写）
| 列 | 字段 | 填写要求 |
| A | 编号 | 自动序号。填了「联系人姓名」才显示,不要手改。 |
| B | 来源 | TARGET(目标公司表) / ENGAGED(领英互动) / REFERRAL(推荐)。下拉选择。 |
| C | 目标公司 | 公司全称。 |
| D | 公司类型 | Colo / IDC / 云厂商 / EPC / 设备原厂 / 其他。 |
| E | 联系人姓名 | LinkedIn 上显示的姓名。这一列是「是否已录入」的判断依据。 |
| F | 职位 | 原文照抄,不要翻译。 |
| G | 职级 | Director 及以上 / Manager / 其他。 |
| H | 国家地区 | 例如 Thailand。 |
| I | LinkedIn主页 | 完整 URL。查重就靠这一列,录入前必须搜一遍。 |
| J | 邮箱 | 拿到后立即回填。回传表与报名链接一律走邮件。 |
| K | 优先级 | A(必做) / B(尽量) / C(有时间再说)。 |
| L | 状态 | 只能填 13 个状态之一,下拉选择。含义见下方「二、状态枚举」。 |
| M | 负责人 | 实习生姓名。看板「人效对比」按这一列统计。 |
| N | 首次触达日 | 发出连接请求那天。看板「已发邀请」按这一列统计。 |
| O | 最近触达日 | 每次动作后更新。用于判断 48 小时规则,务必及时改。 |
| P | 触达次数 | 每次主动触达 +1。 |
| Q | 下次行动日 | 决定每天的待办。每天早上按这一列升序排序。 |
| R | 回复摘要 | 一句话,不要粘贴整段对话。 |
| S | 判定依据 | 付费判定命中的条款,见「付费判定规则」表。 |
| T | 是否付费 | 免费 / 付费 / 待定。拿不准填「待定」并升级主管。 |
| U | 回传表发出日 | 日期。用于 3 天未提醒的预警。 |
| V | 回传表收回日 | 日期。看板「回传表已收」按这一列统计。 |
| W | 注册确认日 | 日期。发出注册成功确认邮件那天。 |
| X | 合规标记 | 空 / DNC。客户要求不再联系时填 DNC,之后不得再触达。 |
| Y | 备注 | 重复、同事已联系等情况。 |
二、状态枚举（「状态」列只能填这 13 个之一）
| 状态 | 含义 | 下一步动作 |
| NOT_STARTED | 已进名单未联系 | 发连接请求 |
| INVITED | 已发请求待通过 | 等待;21 天未通过则撤回 |
| CONNECTED | 已通过未发消息 | 48 小时内发首条消息 |
| MESSAGED | 已发首条消息 | D+3 / D+7 / D+14 跟踪 |
| REPLIED | 有回复 | 判断是否有意向 |
| INTERESTED | 明确有意向 | 要邮箱 → 发回传表 |
| FORM_SENT | 回传表已发 | 3 天未回则提醒一次 |
| FORM_RECEIVED | 已收到回传表 | 24 小时内判定 + 回复 |
| PENDING_PAYMENT | 判定需付费 | 报价与收款 |
| REGISTERED | 注册成功 | 复盘 |
| DECLINED | 明确拒绝 | 礼貌收尾,不再联系 |
| NURTURE | 多次无回复 | 60 天后或再次互动时激活 |
| INVALID | 重复 / 非目标 / 信息错误 | 不再处理 |
三、SLA 逾期规则（看板「风险预警」已自动统计）
| 触发条件 | 时限 | 超时算 |
| 状态 = CONNECTED | 48 小时内发首条消息 | 漏触达,计入日报 |
| 状态 = MESSAGED 且已过「下次行动日」 | 当天完成 | 逾期,次日必须补 |
| 状态 = INTERESTED | 24 小时内索取邮箱并发出回传表 | 黄灯 |
| 状态 = FORM_SENT | 3 天提醒一次 | 逾期需在日报说明 |
| 状态 = FORM_RECEIVED | 24 小时内完成判定与回复 | 黄灯 |
四、三个颜色预警（已在「跟进台账」内置条件格式，整行自动变色）
| 颜色 | 触发条件 | 处理动作 |
| 红色（整行） | 「下次行动日」已过 2 天且状态未结束 | 必须当天清掉,并在日报说明原因。 |
| 黄色（整行） | 状态 = CONNECTED,且最近触达日已过 2 天 | 48 小时内没发首条消息 —— 立即补发。这类客户转化率最高。 |
| 黄色（整行） | 状态 = FORM_SENT,且回传表发出日已过 3 天 | 提醒一次,只提醒一次。 |
| 红色（看板卡片） | 账号通过率 < 30% | 当天停止新增邀请,只做跟进,否则账号会被限制。 |
五、每天固定动作
· 开工前 20 分钟：打开「跟进台账」,按「下次行动日」升序排序,把今天该做的行挑出来,先处理有回复的。
· 确认当天配额：新增连接请求 ≤ 15 条,跟进消息 ≤ 25 条。超配额就顺延到明天,不要硬顶。
· 上午：发连接请求（默认不带备注）;处理昨天到今天的回复,推进「状态」列。
· 下午：跟踪未回复客户（D+3 / D+7 / D+14 三次）;处理领英动态的点赞与评论,按「ENGAGED」来源建联。
· 收工前：把今天所有动作写回表格 —— 更新「最近触达日」「触达次数」「下次行动日」「回复摘要」,再迭代一次状态。
· 每周复盘：看「来源对比」决定下周名单怎么分,看「人效对比」决定谁需要辅导,看「账号通过率」决定下周配额。
