# SOP · 优先级与状态定义

> 来源：领英海外拓客 SOP（精简版）· 已脱敏

二、优先级 A / B / C
三、状态只有 6 个（+1 个终止）

## 优先级判定

| 优先级 | 判定标准 | 怎么处理 |
| A | 公司是 Colo 运营商 / IDC / 云厂商 / EPC 总包 / 液冷原厂，且职位在决策链上 | 优先联系，可用极短备注（≤30 字） |
| B | 公司属产业链相关，职位为执行层 | 空请求 + 通过后发个性化首条消息 |
| C | 公司相关但职位偏外围，或信息不全 | 批量处理，不单独花时间 |

## 状态定义

| 状态 | 什么时候填 | 下一步 |
| 待联系 | 已进名单，还没发请求 | 发连接请求 |
| 已邀请 | 已发请求，等通过 | 通过后 48 小时内发消息；21 天未通过则撤回 |
| 已通过 | 通过了，还没发消息 | 立刻发第一条消息 |
| 已建联 | 已发消息，等回复 | D+3 / D+7 / D+14 三次跟踪 |
| 有意向 | 对方表示想参加 | 要邮箱 → 邮件发回传表 |
| 已完成 | 已确认注册 | 结束，进入复盘 |
| 已拒绝（终止） | 明确拒绝 / 重复 / 非目标 | 礼貌收尾，不再联系 |
