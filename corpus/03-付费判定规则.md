# 客户付费判定规则

> 来源：内部台账文档 / 付费判定规则（已脱敏）

付费判定规则
按顺序问,第一个命中的就是结论。每一步的判定依据都要写进「跟进台账」的「判定依据」列。
判断树
| 顺序 | 判断问题 | 命中结果 |
| 1 | 他是否在我们的定向邀请名单 / 演讲嘉宾 / 赞助商对应客户名单上? | 免费 |
| 2 | 职位是否达到 Director 及以上,且公司属于 Colo / IDC / 云厂商 / EPC 总包 / 液冷设备原厂? | 免费 |
| 3 | 他是否由付费赞助商推荐或随行? | 按该赞助商权益条款执行 |
| 4 | 以上都不满足 | 需付费。把联系人信息与判定依据提交主管,进入报价流程 |
| 5 | 你自己拿不准任何一条 | 升级主管。状态保持 FORM_RECEIVED,等主管答复 |
绝对不要做
✗ 在客户面前自行承诺免费名额。
✗ 自行打折,或自行判断「看起来像大客户就免了」。
✗ 拿不准还硬答。升级不是能力问题,是流程要求 —— 必须升级主管。
✗ 把报价、折扣、权益条款写进邮件正文而不走主管审批。
